# Gestão de Risco — Terminal Danilo Alves™

## Princípio central

O terminal deve proteger o operador antes de qualquer tentativa de ganho.

## Regras obrigatórias

- Nunca operar sem plano.
- Nunca aumentar mão para recuperar perda.
- Nunca operar cansado, irritado ou no impulso.
- Nunca operar notícia sem entender o risco.
- Sempre registrar motivo da operação.
- Sempre definir limite diário.

## Campos mínimos do diário

- Data
- Ativo
- Timeframe
- Direção observada
- Motivo da análise
- Confirmações técnicas
- Risco estimado
- Resultado
- Aprendizado

## Alertas que o sistema deve exibir

- Limite diário atingido
- Sequência de perdas
- Operação sem justificativa
- Ativo com volatilidade elevada
- Horário ruim para operar

## Aviso padrão

Este projeto tem finalidade educacional e organizacional. Mercado financeiro envolve risco. Nenhum módulo deve prometer lucro ou substituir decisão consciente do operador.
